Généré à partir du plan détaillé de Léa, sur la base du site d'Ilyès & Mathilde.

## À COMPLÉTER (cherche « À COMPLÉTER » dans les fichiers)
- **Vols** : compagnie, n° de vols, horaire d'arrivée du 27 août, prix payés (`index.html` footer + `budget.html`)
- **Hôtels** : prix Amanek Kamata + M's Plus Kyoto, types de chambres, photos des chambres réservées (`hotels.html`)
- **guide-original.html** : ajouter ici le fichier HTML original de Léa (le plan ultra-détaillé) pour le conserver

## Structure
- `index.html` — accueil, carte interactive, trajets & prix
- `guide.html` — ~200 idées par thème (badges : priorités, 💡 conseils guide, 💍 plans de Léa)
- `jour-par-jour.html` — les 20 jours détaillés
- `hotels.html` / `budget.html` — hébergements et calculateur
- PWA : installable sur téléphone (Safari → Partager → Sur l'écran d'accueil), consultable hors-ligne
